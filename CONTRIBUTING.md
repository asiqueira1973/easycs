# Como contribuir

Este repositório é uma vitrine: o código está aberto para leitura e estudo, mas o desenvolvimento acontece só do lado da Dab Lab.

## Issues: bem-vindas

Encontrou um bug, ficou com dúvida ou tem uma sugestão? Abra uma [issue](../../issues). Toda issue é lida.

## Pull requests: não são aceitos

Pull requests não são aceitos e são fechados automaticamente. Se você tem uma ideia de mudança, descreva-a numa issue.

Obrigado pelo interesse.
